# NEBRIN ONE App — Release Preview

Production-connected mobile foundation for NEBRIN ONLINE SERVICE COMPANY LIMITED.

Includes Supabase staff authentication, backend-driven roles/permissions, Digital Office attendance and breaks, CEO/Manager Command Centre, Security Centre, Workflow Centre, Finance Centre, and Notification Centre. The existing production website is not modified by this mobile workspace.

Release branch: `nebrin-one-release`.

Backend functions: `nebrin-app-bootstrap`, `nebrin-digital-office`, `nebrin-command-centre`.
