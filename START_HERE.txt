AI NOTE
The included AI Help function performs automatic rule/knowledge-based first-line diagnosis and creates an IT ticket.
A true generative-AI model requires a separately connected AI provider/API. The system does NOT pretend an external AI model is active when no provider is configured.

SECURITY NOTE
No system can guarantee 100% prevention of fraud or attacks. The included controls identify high-risk events, preserve audit evidence,
restrict access using database policies, create incidents and route sensitive alerts. Human review remains required before accusing or disciplining anyone.


NEW STAFFING + AI VACANCY WORKFLOW
- Every HOD can submit an Additional Employee Request for their own department.
- Route: HOD -> Secretary -> HR HOD -> Manager.
- Manager approves/rejects the staffing need and returns the decision to HR.
- If approved, HR uses AI Draft Vacancy. The drafting engine identifies the department from the approved staffing request and adapts requirements/responsibilities to that department.
- HR reviews before publishing. Publishing sends the vacancy to the public Careers/Vacancy page and notifies the requesting HOD.
- If rejected, HR can close the request and send the Manager's response back to the requesting HOD.
- Supporting file URL can be attached to the staffing request.
